# Gaming Hub

A responsive landing page for a Pakistan-focused PUBG Mobile tournament community, featuring scrims, custom rooms, cash prize event information, and tournament FAQs.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. The site has no build step or external runtime dependencies.

## Current scope

This is a static front-end preview. Tournament schedules, registrations, standings, social channels, and prize details are not connected to a backend and should be added before accepting players or advertising live events.
